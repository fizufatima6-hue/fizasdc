Live example (code displayed as text):
To create a paragraph in HTML, write &lt;p&gt;Hello&lt;/p&gt;, which renders on the page as <p>Hello</p>. Use &lt; and &gt; whenever you want to show HTML tags to the reader rather than have the browser execute them.
